# Amazon Infotech India — Website

This is a static, mobile-responsive website ready for Netlify.

## Files
- index.html — complete website
- style.css — design
- script.js — searchable sample catalogue
- assets/logo.jpg — supplied company logo
- assets/md-ruchi-chauhan-khan.jpg — supplied MD photo

## Before publishing
1. Open `script.js`.
2. Replace the sample `books` entries with the real catalogue.
3. If needed, edit the address/email/phone in `index.html`.
4. The quote form is configured for Netlify Forms (`data-netlify="true"`).

## Free Netlify deployment from phone
1. Create/sign in to GitHub in Chrome.
2. Create a new repository, e.g. `amazon-infotech-india`.
3. Upload all files/folders from this package, keeping the `assets` folder.
4. Open Netlify and choose **Add new site → Import an existing project**.
5. Select GitHub and the repository.
6. For a plain static site, leave Build command empty and Publish directory as `/`.
7. Deploy.
8. Netlify will give a free `*.netlify.app` address.
9. A custom `.com`/`.in` domain can later be purchased from a registrar and connected to Netlify.

## Catalogue
The site currently shows clearly marked sample entries so no unverified book data is presented as real. Replace them with your actual list.
